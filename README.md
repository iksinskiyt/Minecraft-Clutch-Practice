
# Minecraft Clutch Practice Map
<sub>*Tested on 1.16.1. Other versions might not work.*</sub>

---

Since I haven't found anything to practice my **W drags**, I made this simple yet fully featured practice map.

## Features

* **Adjustable Drop Height**
* **Water Bucket Clutching**
* **Boat Clutching** 
*  **Height Presets**

## How to use items?
Hover over the item you want to use and drop it with **Q**.
